# Playbook-RAG

Files related to the Playbook-RAG system demonstration for EACL 2027.

Includes

- A collection of anonymized source documents (`data/documents`) used in the Playbook-RAG system demonstration.
- A test set of queries (`data/dataset.csv`) used to evaluate the Playbook-RAG system.
